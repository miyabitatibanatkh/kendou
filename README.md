# IMU 与传感器验证分支

这个分支用于验证穿戴式传感器是否比纯视频更适合剑道动作分析，尤其是挥剑速度、角速度、冲击、身体转动和发力时序。

## 背景判断

穿护具后，纯视觉姿态估计会遇到天然限制：

- 护具遮挡真实关节轮廓
- 袴和身体重叠导致髋、膝、脚点不稳定
- 竹刀遮挡手腕和肘
- 快速挥剑导致运动模糊
- 背面和侧身视角容易左右混淆

如果目标只是画骨架，视觉模型还能继续尝试。但如果目标是“力学分析”或“发力分析”，单目视频不够。应力、力、冲击、角速度这类量需要传感器辅助。

参考资料：

- Xsens motion capture：https://www.xsens.com/get-started/motion-capture
- Xsens 官方资料提到全身惯性动作捕捉系统可用 17 个惯性传感器记录人体运动。

## 可验证的传感器路线

### 1. 手腕或竹刀 IMU

最现实的第一步。可以测：

- 挥剑角速度
- 挥剑加速度
- 击打瞬间峰值
- 起手和收刀时机
- 左右手协同趋势

推荐先放置：

- 竹刀柄部一个 IMU
- 右手腕一个 IMU
- 腰部一个 IMU

### 2. 全身 IMU

类似 Xsens MVN 这种系统，可以做更完整的 3D 动作捕捉。

优点：

- 不依赖摄像机视角
- 不怕竹刀遮挡身体
- 可在道场真实环境采集

缺点：

- 成本高
- 穿戴和标定复杂
- 位置会有漂移，需要传感器融合和校准

### 3. 压力鞋垫或力板

用于分析：

- 蹬地时机
- 重心转移
- 左右脚受力
- 踏步冲击

### 4. 靶子或竹刀冲击传感器

如果目标是击打力，建议不要只靠视频估计。可以考虑：

- 靶子上加压力传感器
- 竹刀柄部加 IMU
- 用峰值加速度和接触瞬间时间窗估计击打事件

### 5. EMG 肌电

可以分析肌肉发力时序，但设备、贴片位置、信号处理难度都更高。建议放在后期。

## 第一轮低成本实验

先不要买昂贵动捕系统。建议第一轮用低成本 IMU 验证可行性：

1. 选择一个支持蓝牙或串口导出 CSV 的 IMU。
2. 绑在竹刀柄部。
3. 同时录视频。
4. 每次挥剑记录：
   - 时间戳
   - 三轴加速度
   - 三轴角速度
5. 在视频里找到挥剑开始、击打瞬间、收刀三个事件。
6. 对齐 IMU 曲线和视频帧。

## 与当前项目的接入方式

新增数据目录：

```text
data/sensor/
```

新增模块：

```text
src/sensors/imu_reader.py
src/sensors/sync.py
src/analysis/imu_metrics.py
```

第一批指标：

- 最大角速度
- 最大加速度
- 击打峰值时间
- 挥剑持续时间
- 身体转动峰值
- 手腕和腰部动作延迟

## 成功标准

如果 IMU 曲线能稳定区分：

- 起手
- 加速
- 击打
- 收刀

并且这些事件能和视频帧对齐，就值得继续投入。

如果目标是精确力学，应进一步考虑：

- 压力传感器
- 力板
- 多 IMU 姿态融合
- 专业动捕系统

## 风险

- IMU 位置和绑法会强烈影响数据。
- 加速度不能直接等同于力。
- 角度会漂移，需要校准。
- 多传感器同步是后续难点。
- 真正的“应力”需要材料、接触、力和几何模型，不是单靠 IMU 能直接得到。
