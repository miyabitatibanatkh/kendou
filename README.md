# Kendo Motion Analysis 学习项目

## 项目目标

我要使用Python、OpenCV和人体姿态识别技术，开发一个剑道动作视频分析项目。

这个项目同时用于学习：

1. Python项目开发
2. OpenCV视频处理
3. 人体关键点识别
4. 坐标与角度计算
5. CSV数据输出
6. Streamlit网页开发
7. Git和GitHub
8. 项目部署

第一版只分析单人、固定机位、侧面拍摄的剑道视频。

第一版计划分析：

- 左右肘关节角度
- 左右膝关节角度
- 身体前倾角度
- 头部上下移动
- 左右脚的位置变化
- 视频中的关键帧
- 每帧分析数据

暂时不要实现：

- 自动判断动作正确或错误
- 多人识别
- 竹刀识别
- 深度学习模型训练
- 与高段者视频自动评分
- 复杂的商业功能

## 模块职责

### `src/video/reader.py`

负责：

- 打开视频
- 判断视频是否成功打开
- 获取FPS
- 获取宽高
- 获取总帧数
- 逐帧读取

不要包含人体识别逻辑。

### `src/video/writer.py`

负责：

- 创建输出视频
- 写入处理后的帧
- 释放视频资源

### `src/pose/detector.py`

负责：

- 初始化姿态识别器
- 接收一帧图像
- 返回人体关键点结果

不要进行剑道评价。

### `src/pose/landmarks.py`

负责：

- 取得指定人体关键点
- 将归一化坐标转换成像素坐标
- 检查关键点可信度

### `src/analysis/geometry.py`

只保存通用数学函数，例如：

- 两点中点
- 两点距离
- 三点夹角
- 相对于垂直线的角度

这个文件不能依赖OpenCV或Streamlit。

### `src/analysis/kendo_metrics.py`

负责剑道相关指标，例如：

- 膝关节角度
- 肘关节角度
- 身体前倾角度
- 头部高度变化
- 左右脚移动距离

### `src/visualization/overlay.py`

负责：

- 在视频上画骨架
- 画点和线
- 显示角度
- 显示帧号和时间

### `src/export/csv_exporter.py`

负责：

- 保存每帧数据
- 输出CSV
- 确保列名一致

### `app.py`

最后阶段才创建Streamlit页面，负责：

- 上传视频
- 显示处理进度
- 启动分析
- 显示结果
- 下载分析视频
- 下载CSV

业务计算不要直接写在`app.py`里。

## 代码质量要求

1. 使用Python类型注解。
2. 使用`pathlib.Path`处理路径。
3. 函数保持单一职责。
4. 避免全局可变状态。
5. 对文件不存在、视频无法打开等情况进行错误处理。
6. 资源使用后必须释放。
7. 通用数学函数应有单元测试。
8. 不将测试视频提交到Git仓库。
9. 不把大型模型或生成视频提交到Git。
10. 不保存用户上传的视频超过必要时间。
11. 不声称代码成功，除非实际运行过。
12. 每次修改后检查`git diff`和测试结果。

## 剑道分析表达原则

项目第一版只提供客观测量，不直接判断技术是否正确。

合适的输出：

- 打击时右膝角度为142.5度。
- 身体前倾角最大值为17.3度。
- 左脚在右脚落地后0.28秒开始跟进。
- 与本人的基准视频相比，头部上下移动增加了3.2厘米。

不合适的输出：

- 你的面打是错误的。
- 你的姿势一定不正确。
- 这个动作不符合剑道标准。

由于2D视频、摄像机角度、防具遮挡和关键点识别误差，结果只能作为练习参考。
