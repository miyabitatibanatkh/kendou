# OpenCap 验证分支

这个分支用于验证 OpenCap 这类 markerless biomechanics 工具是否适合剑道动作分析。

## 背景判断

当前项目使用视频关键点计算角度和偏移，适合做轻量级动作可视化。但如果目标上升到生物力学分析，例如关节力矩、肌肉力、动作动力学，普通 2D 姿态估计是不够的。

OpenCap 的方向更接近运动生物力学平台：使用一个或多个手机视频采集，云端处理，输出运动学和动力学相关结果。官方介绍强调低成本、便携、可用于人体运动分析，并提到可以下载结果、用 Python 工具进一步分析，例如估计 kinetics。

参考资料：

- OpenCap 官方网站：https://www.opencap.ai/

## 第一轮目标

先验证 OpenCap 对剑道动作是否可用，不急着接入代码：

- 是否支持快速上肢动作
- 是否支持手持竹刀场景
- 是否要求固定动作类型，例如步态、深蹲、跳跃
- 是否能处理护具遮挡
- 是否能导出关节角度、力矩或肌肉力相关数据

## 建议实验设计

准备三类视频：

1. 无护具、慢动作、正面或斜前方
2. 无护具、正常速度、完整挥剑
3. 穿护具、正常速度、完整挥剑

每类视频记录：

- OpenCap 是否能完成处理
- 输出了哪些数据
- 关节角度是否合理
- 是否需要多机位
- 是否能导出 CSV 或可被 Python 读取的数据

## 与当前项目的关系

如果 OpenCap 能稳定输出关节角度和动力学数据，当前项目可以转为：

- 视频可视化层
- 剑道指标计算层
- OpenCap 数据导入和对比层

也就是说，不一定要用 OpenCap 替代当前代码，而是把它当成更高质量的数据源。

## 成功标准

第一阶段成功标准：

- OpenCap 能处理至少一段正面或 45 度剑道动作视频
- 能导出可复用数据
- 关节角度随动作变化趋势合理
- 比当前 2D MediaPipe 指标更稳定

如果这些成立，再考虑接入：

```text
src/importers/opencap_importer.py
```

## 风险

- OpenCap 可能更适合步态、下肢、跳跃、深蹲等标准动作，对剑道上肢高速挥动未必稳定。
- 护具和竹刀仍可能破坏 markerless 识别。
- 如果需要多机位，采集门槛会上升。
- 云端平台可能不适合所有数据隐私需求。

## 不适合用 OpenCap 解决的问题

- 实时训练反馈
- 竹刀剑尖轨迹
- 击打瞬间冲击力
- 护具内真实关节位置

这些问题更适合结合 IMU、压力传感器或自定义视觉模型。
